# Overview

## backup_old

The backup_old folder serves as an archive for previous experimental iterations.

## data

The data directory stores all experimental datasets, including raw sensor readings and processed signals from piezo actuator characterization experiments.

## lock_in

The lock_in module implements Lock-in Detection for Piezo Actuators signals, enabling precise extraction of amplitude and phase information even in noisy environments.

## training_VIT

The training_VIT directory contains Vision Transformer (ViT) training and classification pipelines.

## training_fft

The training_fft directory provides Fast Fourier Transform-based training pipelines, enabling efficient frequency-domain analysis from time-series actuator measurements.

## Closed_loop

The Closed-loop folder contains everything related to closed-loop piezo control.
