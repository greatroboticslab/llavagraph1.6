# mamba_zamba

Few-shot diagnostic report generation for piezoelectric actuators using **Zamba2-7B-instruct** (Mamba-2 + Transformer hybrid).

The system generates structured diagnostic reports (DIAGNOSIS, CORRECTION, CORRECTION VECTOR) from waveform measurement data. CORRECTION VECTOR values are computed analytically from input features (100% accuracy). DIAGNOSIS and CORRECTION text is generated by the LLM using 1-shot in-context learning.

---

## Model

| Property | Value |
|----------|-------|
| Model | Zyphra/Zamba2-7B-instruct |
| Architecture | Mamba-2 + Transformer hybrid |
| Parameters | 7B |
| Precision | bfloat16 |
| Hardware | NVIDIA A100 80GB |
| Method | 1-shot few-shot inference (no fine-tuning) |

| noise | 92 | 0.386 | 0.208 | 11.7 |
| **Overall** | **487** | **0.382** | **0.209** | **11.7** |

- Average generation time per sample: ~22 seconds
- CORRECTION VECTOR accuracy: 100% (analytically computed)
- Inference speed is consistent across all waveform types

## Output Format

```
DIAGNOSIS: <LLM-generated text describing distortion type, physical cause,
            quantitative measurements>

CORRECTION: <LLM-generated control strategy to restore commanded waveform>

CORRECTION VECTOR:
  phase_offset_deg             = -172.200
  amplitude_scale              = +1.1512
  harmonic_2_amp               = -0.1624
  harmonic_3_amp               = -0.0992
  dc_offset_nm                 = +0.0000
  hysteresis_ff_nm             = +0.0000
```

CORRECTION VECTOR fields vary by waveform type:

| Waveform | Fields |
|----------|--------|
| sine | phase_offset_deg, amplitude_scale, harmonic_2_amp, harmonic_3_amp, dc_offset_nm, hysteresis_ff_nm |
| square | duty_cycle_trim, edge_sharpness_deficit, harmonic_2_amp, dc_offset_nm |
| ramp | rise_linearity_correction, fall_linearity_correction, asymmetry_correction, amplitude_scale, dc_offset_nm |
| pulse | ringing_suppression_target, pulse_duty_cycle_measured, amplitude_scale, dc_offset_nm |
| noise | whitening_required, rms_measured_nm, gaussianity_error, autocorr_lag1 |

## Files

| File | Description |
|------|-------------|
| `infer_zamba.py` | Few-shot inference script (5 test samples) |
| `eval_zamba.py` | Full evaluation on 487 test samples with BLEU/ROUGE metrics |
| `visualize_results.py` | Generates waveform + report figures |
| `run_zamba.sbatch` | SLURM job for inference |
| `run_eval.sbatch` | SLURM job for full evaluation |

---

## Usage

**Run inference (5 samples):**
```bash
sbatch run_zamba.sbatch
```

**Run full evaluation (487 samples):**
```bash
sbatch run_eval.sbatch
```

**Generate visualization figures:**
```bash
python visualize_results.py --results results/eval_results.jsonl --out figures --n 2
```

## Pipeline

```
Waveform measurement data (input features)
        |
        |-- parse_features() --> extract RMS, THD, phase lag, harmonics, etc.
        |
        |-- compute_cv()     --> CORRECTION VECTOR (analytical, 100% accurate)
        |
        |-- Zamba2-7B-instruct (1-shot few-shot)
                |
                +--> DIAGNOSIS text
                +--> CORRECTION text
        |
        v
Diagnostic report + CORRECTION VECTOR
```
