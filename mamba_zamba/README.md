# mamba_zamba

Few-shot diagnostic report generation for piezoelectric actuators using **Zamba2-7B-instruct** (Mamba-2 + Transformer hybrid, 7B parameters).

Given waveform measurement data, the system generates three outputs:
- **DIAGNOSIS** — identifies what is wrong with the waveform and why
- **CORRECTION** — describes the control strategy to fix it
- **CORRECTION VECTOR** — exact numerical parameters for the Moku PID controller (computed analytically, 100% accurate)

---

## How it works

No fine-tuning. The model receives one real training example as context (1-shot), then generates the report for the new waveform.

```
[Training example as context]
Input:  measured waveform features (THD, phase lag, harmonics, RMS...)
Output: DIAGNOSIS + CORRECTION

[New test sample]
Input:  measured waveform features
Output: DIAGNOSIS + CORRECTION  <-- generated by Zamba2-7B
        CORRECTION VECTOR       <-- computed from formulas (100% accurate)
```

## Example: Sine Waveform

Real measured waveform (left) and LLM-generated diagnostic report (right):

![sine example](figures/sine_example.png)

**Input features:**
```
COMMANDED WAVEFORM: sine at 20.1 Hz  |  Target peak: ±335.7 nm
Phase lag:         172.2°  (expected 1.84° from linear model)
THD:               22.01%
Crest factor:      1.628   (ideal: 1.414)
2nd harmonic:      0.1624
3rd harmonic:      0.0992
Amplitude drift:   18.87 nm  (Q1 to Q4)
```

**Generated output:**
```
DIAGNOSIS:
The commanded sine at 20.1 Hz displays substantial nonlinearity and
distortion. Despite achieving the desired peak displacement of 335.7 nm,
the sine-fit residual is 99.98%, suggesting the output is far from
sinusoidal. The phase lag of 172.2° greatly surpasses the expected 1.84°,
indicating strong nonlinear effects.

CORRECTION:
To restore the commanded waveform, implement a combination of feedforward
and feedback compensation strategies. Apply a feedforward correction to
mitigate the excessive phase lag of 172.2° using a lead network tuned to
the dominant frequency of 20.10 Hz. Use a feedback loop to dampen any
resonances and ensure stability through proper gain adjustment.

CORRECTION VECTOR:
  phase_offset_deg             = -172.2000
  amplitude_scale              = +1.1512
  harmonic_2_amp               = -0.1624
  harmonic_3_amp               = -0.0992
  dc_offset_nm                 = +0.0000
  hysteresis_ff_nm             = +0.0000
```

## Example: Square Waveform

![square example](figures/square_example.png)

**Input features:**
```
COMMANDED WAVEFORM: square at 100 Hz  |  Target peak: ±521.6 nm
THD:               56.93%  (ideal: 48.3%)
Duty cycle:        0.4763  (ideal: 0.500)
Edge sharpness:    0.9166  (ideal: 1.000)
2nd harmonic:      0.0259
Amplitude drift:   0 nm
```

**Generated output:**
```
DIAGNOSIS:
The measured output differs from the commanded square wave primarily
because of nonlinear distortion caused by excessive phase lag. This
results in a high total harmonic distortion (THD) of 56.93%. The crest
factor of 1.608 indicates overshooting on the peaks. The odd/even
harmonic ratio of 150.7 suggests strong third harmonic content
contributing to the distorted waveform.

CORRECTION:
To improve the waveform fidelity, reducing the phase lag through
adjustments in the control loop parameters will help minimize the
nonlinear distortion. Advancing the phase angle by approximately 3.0
degrees should bring the observed phase lag closer to the predicted
value.

CORRECTION VECTOR:
  duty_cycle_trim              = +0.0237
  edge_sharpness_deficit       = +0.0834
  harmonic_2_amp               = -0.0259
  dc_offset_nm                 = +0.0000
```

## Files

| File | Description |
|------|-------------|
| `infer_zamba.py` | Inference script (5 test samples) |
| `eval_zamba.py` | Full evaluation on 487 test samples |
| `visualize_results.py` | Generate waveform + report figures from eval results |
| `make_figures.py` | Generate README example figures locally |
| `run_zamba.sbatch` | SLURM job for inference |
| `run_eval.sbatch` | SLURM job for full evaluation |

## Usage

```bash
# Run inference on 5 samples
sbatch run_zamba.sbatch

# Run full evaluation (487 samples, ~3 hours on A100)
sbatch run_eval.sbatch

# Generate visualization figures (after eval)
python visualize_results.py --results results/eval_results.jsonl --out figures --n 2
```
